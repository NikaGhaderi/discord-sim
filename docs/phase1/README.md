# Phase 1 Documentation

This folder holds Phase 1 planning artifacts: architecture decision records
(ADRs), API contracts, and wireframe references linked from Jira tickets.

Add ADRs as `adr-XXX-title.md` using the template below (see
`CONTRIBUTING.md` §9).

## ADR Template

```markdown
# ADR-XXX: Title

## Status
Proposed | Accepted | Superseded

## Context
What problem are we solving? What constraints apply?

## Decision
What did we decide to do?

## Consequences
What becomes easier or harder as a result?
```
